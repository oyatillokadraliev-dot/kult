# Как добавить/заменить фото тренера

## Папка с фотографиями
Все фото лежат в: `site/images/trainers/`

```
site/images/
├── hero-collage.jpg     ← фон главной страницы
├── hero-mobile.jpg      ← фон главной на телефоне
├── equipment.jpg        ← фон личного кабинета
├── logo-dark.png        ← логотип в шапке
├── logo-cream.png       ← логотип на тёмном фоне
└── trainers/
    ├── zosya.jpg        ← фото Зоси
    ├── ksenia.jpg       ← фото Ксении
    ├── salma.jpg        ← фото Сальмы
    ├── farida.jpg       ← фото Фариды
    └── viktoria.jpg     ← фото Виктории
```

## Как заменить фото тренера (3 шага)

1. Подготовь фото:
   - Формат: JPG
   - Размер: примерно 400×530 пикселей (вертикальное, соотношение 3:4)
   - Назови файл точно так же: `zosya.jpg`, `ksenia.jpg` и т.д.

2. Скопируй файл в папку `site/images/trainers/`
   (заменяя существующий файл с тем же именем)

3. Закинь в GitHub:
   ```bash
   git add site/images/trainers/
   git commit -m "обновила фото тренеров"
   git push
   ```
   GitHub Pages обновится автоматически через 1-2 минуты.

## Если что-то пошло не так
Если фото не загрузилось — сайт автоматически покажет серый placeholder
с иконкой человечка. Значит имя файла не совпадает.
Проверь: файл должен называться строчными буквами без пробелов,
именно как написано выше.
